## 2026-09-10 (오너 지적 대응 — 정규 주차 아님)

주간 루프와 별개로, 오너가 6가지를 지적해 그날 처리한 기록.
**루프의 성적표는 2번이다** — 실명 노출은 내가 먼저 찾았어야 했다.

**즉시 조치**

- **실명 노출** — 화면이 `users.name`(가입 폼 '이름 / 홍길동'으로 받은 실명)을
  찍고 있었다. `utils/userName.js` 하나로 모으고 서버의
  `nickname or name` 대체까지 끊었다. **프론트만 고쳤을 때는 안 고쳐진 상태였다** —
  서버가 nickname 자리에 실명을 담아 보내고 있었기 때문이다.
  DB 의 실명 11건은 백업 + settings 스냅샷 후 삭제했다.
- **화이트 테마 밝기** — 배경↔카드 명도차 ΔL* 1.8 → 4.7, 테두리 대비 1.10 → 1.23.
  글자 대비(10.35:1)는 원래 좋았다. 문제는 글자가 아니라 면이었다.
- **기본 테마 auto** — 신규 사용자는 OS 를 따른다(light/dark 실측 확인).
- **동시 접속 1차 병목** — 스레드풀 슬롯 40 → 128. 엔드포인트 320개가 전부
  동기라 블로킹 I/O 가 슬롯을 붙잡는 구조였다.
  **워커를 늘리지는 않았다** — `_demo_ai_calls` 가 프로세스 지역이라 데모 AI
  일일 상한 40 이 조용히 80 이 되고 `ttl_cache` 적중률이 반토막 난다.
- **인앱 피드백 버튼** — 지인 10건이 카톡으로 왔다. 밖에서 오면 "어느 화면이요?"
  를 되묻게 되고, 그 왕복 한 번이 대부분의 피드백을 사라지게 한다.
  화면·기기·레이아웃·버전을 자동으로 붙이고 **금액은 담지 않는다.**

**로드맵 등재 (착수는 오너 결정)**

- 자산군 나침반 — 분석이 "가진 주식 안에서"만 본다. 금·은·환율이 빠져 있다.
- 전문가 모드 = 정보 밀도 — 다크 vs 차콜의 실제 차이는 강조색 하나뿐(ΔE 89.6)이고
  배경은 ΔE 7.0 이다. 색으로는 "전문적"을 만들 수 없다.
- Ampere A1 이전 — RAM 25배·코어 2배가 0원.

  돌았다는 뜻이다 — 아무도 모르는 디렉터리에서만 도는 가드는 가드가 아니다.
  → 의존성 추가 + `npm run guard:all` 로 고정.
- **`privacy-scan.mjs` 가 공개 기업 실적을 개인 자산으로 오인했다.**
  "기아 매출 33조370억원"에서 `370억` 을 떼어내 🔴 를 띄웠다. 왼쪽 경계
  `(?<![\d,.조억만])` 를 넣어 더 큰 숫자의 안쪽을 잘라 잡지 않게 했다.
  그물은 그대로다 — "1억2,000만원" 이면 `1억` 쪽이 여전히 걸린다.
- **`ux-firstuse.mjs` 의 화면 밖 규칙이 죽어 있었다.** 자기검사로 드러났고 원인이 두 겹이었다.

  재현 CSS 자체가 결함을 못 만들고 있었다(배너를 맨 위로 올린 것이 고침이었으므로
  `order` 로 되돌려야 결함이 살아난다). 잘라내는 조상을 찾는 방식으로 바꿔 해결.
