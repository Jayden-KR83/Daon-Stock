# 스크린샷 캡처 체크리스트

저장 위치: `reviews/out/shots/` · 파일명 규칙: `<폭>_<화면>_<상태>_<테마>.png`
예) `m360_분석_툴팁열림_light.png`, `web_발굴_행펼침_dark.png`

- **폭**: `m360`(모바일 360~400px) + `web`(데스크톱 ≥1024px) 둘 다.
  - 모바일은 브라우저 DevTools 반응형(360×800 권장) 또는 실기기.
- **테마**: 라이트/다크가 모두 있으면 각각. 하나뿐이면 그것만.
- **상호작용 상태**: 툴팁·펼침·시트·드롭다운은 **열린 상태**로 캡처(정적 스샷만 보는 Gemini 한계 보완).

## 필수 화면 (○ = 반드시)

| 화면 | 캡처 상태 | 폭 | 비고 |
|---|---|---|---|
| ○ 하단 네비(모바일) | 기본 + **더보기 시트 열림** | m360 | 최근 5칸+더보기로 변경됨 |
| ○ 사이드 네비(웹) | 기본 | web | |
| ○ 로그인/가입 | 빈 폼 + (가능하면)에러 상태 | m360, web | 초대코드 입력 포함 |
| ○ 포트폴리오(보유) | 목록 + 요약 배너 | m360, web | 실데이터 필요 → 오너 캡처 |
| ○ 관심 | 목록 | m360, web | |
| ○ 분석 | 요약 지표 + **MDD/샤프 툴팁 열림** + 건강점수 + 전략 | m360, web | 지표 툴팁이 이번 변경 핵심 |
| ○ 종목 | 차트 + **AI 심층분석 + 출처 섹션 펼침** | m360, web | 출처 표기 확인 |
| ○ 발굴 | 표 + **행 펼침(레이더)** + **점수 산정 방식 펼침** + 필터 행 | m360, web | 필터·산정근거 이번 변경 |
| △ 시장 | 지수·거래량 | m360, web | |
| △ 등록 | 폼 | m360 | |
| △ 설정/관리 | 기본 | m360 | |

○=필수, △=여유되면.

## 캡처 팁
- 모바일은 **가로 스크롤이 생기는지** 특히 주의해 잡아라(360px에서 잘림·겹침이 잘 드러남).
- 개인정보(실계좌 잔액 등)가 부담되면 데모 계정 또는 값 가림 후 캡처.
- 한 화면이 길면 스크롤 상단/하단 2장으로.

## Claude 하네스로 대체 가능한 화면 (인증 불필요)
로그인·하단네비·더보기 시트·발굴 필터/산정방식 등 정적 레이아웃은 Claude가 실 CSS로
렌더해 스샷 생성 가능(360/400px). 실데이터·인증 화면(포트폴리오·분석·종목 AI결과)은
오너가 실앱에서 캡처해야 진짜 3자 검증이 된다.
